# Day 2 – Building an AI Assistant with Memory

## Overview
Today I learned how to make an AI assistant maintain conversation context using chat history. I implemented a conversational assistant that remembers recent interactions during a session.

## Concepts Learned
- Maintaining conversation history using Python lists.
- Passing previous messages to an LLM.
- Implementing short-term conversational memory.
- Limiting conversation history using `MAX_TURNS`.
- Using decorators for function logging.
- Handling API errors using exception handling.
- Implementing an interactive chat loop.

## Mini Project
### CampusBridge AI Assistant with Memory
Customized an AI assistant for CampusBridge, a college-mediated placement portal. The assistant maintains recent conversational context to provide more relevant responses to students regarding platform features and placement-related queries.

## Technologies Used
- Python
- OpenAI Python SDK
- Groq API
- GPT-OSS-20B

## Outcome
Built a prompt-based AI assistant with short-term conversation memory, basic function logging and error handling.
