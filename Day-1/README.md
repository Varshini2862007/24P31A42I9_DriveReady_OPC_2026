# Day 1 – Introduction to AI Agent Building

## Overview
Today I learned the basics of building an AI assistant using an LLM API. I explored how system prompts define an AI's role, knowledge, rules and response format.

## Concepts Learned
- Connecting to an LLM using an API.
- Using the OpenAI Python library with Groq API.
- Understanding system and user messages.
- Using system prompts to define an assistant's role, facts, rules and response style.
- Understanding temperature and token usage.

## Mini Project
### CampusBridge AI Assistant
I customized a basic AI assistant for my CampusBridge placement portal. The assistant is designed to help students with placement-related queries, profile preparation, applications and platform features.

## Technologies Used
- Python
- OpenAI Python SDK
- Groq API
- GPT-OSS-20B

## Outcome
Successfully explored how to create a prompt-based AI assistant and customize it for a real-world project idea.
